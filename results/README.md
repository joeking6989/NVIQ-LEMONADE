# Real Measurement Provenance

This directory is reserved for **real live-Lemonade results**. Automated fixture outputs belong in tests/examples and must not be presented as hardware benchmark data.

## Required provenance for a published run

A real result set must include:

1. the untouched `comparison.json` or `report.json` generated by NVIQ × Lemonade;
2. the matching Markdown and HTML artifacts;
3. NVIQ × Lemonade git commit SHA or release tag;
4. Lemonade Server version from `/v1/health`;
5. model IDs and recipes from `/v1/models`;
6. host/device information returned by `/v1/system-info`;
7. date/time of the run and whether the system was on AC/battery if relevant;
8. any non-default Lemonade/model runtime options used;
9. a statement that the run used a live Lemonade Server rather than the test fixture.

## Recommended directory layout

```text
results/
  YYYY-MM-DD-system-short-name/
    README.md
    comparison.json
    comparison.md
    comparison.html
    models/
      ...
```

## Recommended run command

```bash
nviq-lemonade demo --output-dir results/YYYY-MM-DD-system-short-name
```

For an explicit model set:

```bash
nviq-lemonade compare \
  --model MODEL_A \
  --model MODEL_B \
  --output-dir results/YYYY-MM-DD-system-short-name
```

## Publication rule

Do not hand-edit the machine-readable result to make a model or device look better. If a run is invalid because of setup, publish a fresh run and document why the earlier run was rejected.
